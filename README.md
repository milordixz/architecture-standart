## Архитектурная логика

- АБС остаётся источником утверждённых ставок и банковских операций.
- Сервис депозитов использует отдельные проекции, события и идемпотентную обработку заявок.
- Банковский кол-центр получает публичные ставки через внутренний API.
- Партнёрский кол-центр получает подписанные файлы через SFTP-шлюз в DMZ и возвращает ACK.
- Персональные ставки, персональные данные и кредитные риски не передаются во внешний контур.
- Все архитектурные решения связаны с требованиями, сценариями, схемами и планом реализации.
