# RoadMap: передача ставок, MVP за 6 месяцев, цель за год

## Этапы

| Период | Результат                                                                                   |
|--------|---------------------------------------------------------------------------------------------|
| M1     | Согласованы модель ставок, правила публикации, контракты файла, ACK, доступы и SLO.         |
| M2–M3  | Готовы Kafka, SQL snapshots, SFTP DMZ, сервис распространения и API банковского кол-центра. |
| M4     | Работают экспорт, подпись, импорт партнёра, проверка версии и `validUntil`.                 |
| M5     | Завершены сквозные проверки, нагрузка, DR, безопасность и обучение операторов.              |
| M6     | Проведены пилот и выпуск MVP для обоих кол-центров.                                         |
| 1 год  | Возможны защищённый внешний канал/портал и персональные ставки после идентификации клиента. |

## Критерии MVP

- банковский кол-центр получает утверждённую ставку через API;
- партнёр получает подписанный файл через SFTP и возвращает ACK;
- версия и срок действия совпадают в обоих каналах;
- просроченные или повреждённые данные не активируются;
- сбои доставки, повторы и отсутствие ACK видны в мониторинге.

Проектные ориентиры: ставка появляется в банковском кол-центре не позднее 60 секунд, импорт партнёром — не позднее 15
минут в штатном режиме. Эти значения требуют подтверждения на M1.
